# Dungeon Deck — Dark Pixel Roguelike

A browser-based dungeon deckbuilding roguelike.

## Run locally

Open `index.html` in a modern web browser.

## GitHub Pages

This project is a static website and can be hosted directly with GitHub Pages. No build step or server is required.
